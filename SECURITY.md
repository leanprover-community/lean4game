# Security Policy

## Supported Versions

We only support the latest version of the game server. Older versions are encouraged to stay updated.

## Reporting a Vulnerability

Please use the github feature to report a security vulnerability ([report vulnerability](https://github.com/leanprover-community/lean4game/security/advisories/new))
or email adam@math.hhu.de

We will try to get back to you as soon as possible.
